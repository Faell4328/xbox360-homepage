# Home

Home inspirada no dashboard do Xbox 360, feita em React + Vite + Tailwind CSS, com rotas via React Router.

## 🚀 Estrutura

```text
/
├── public/              # assets (imagens, sons)
├── src
│   ├── components       # Dashboard, Tile, Menu, Notification, animations, sounds
│   ├── pages            # HomePage, GamesPage
│   ├── style            # CSS global e de componentes
│   ├── App.tsx          # definição das rotas
│   ├── main.tsx         # entry point
│   └── input.css        # entrada do Tailwind
├── index.html
└── vite.config.ts
```

## 🧞 Commands

| Command           | Action                                      |
| :---------------- | :------------------------------------------ |
| `npm install`     | Instala as dependências                     |
| `npm run dev`     | Sobe o servidor de desenvolvimento (Vite)   |
| `npm run build`   | Typecheck + build de produção em `./dist/`  |
| `npm run preview` | Pré-visualiza o build localmente            |
